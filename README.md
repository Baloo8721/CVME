# CVME - Professional Resume/CV

A clean, responsive personal resume/CV website showcasing professional experience, skills, and contact information.

## Features

- Responsive design that works on all devices
- Clean, modern UI with easy navigation
- Downloadable PDF resume
- Contact information with clickable links

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Baloo8721/CVME.git
   ```

2. Open `cv.html` in your web browser to view the resume.

## Technologies Used

- HTML5
- CSS3 (with Tailwind CSS)
- JavaScript

## Deployment

This project is deployed using GitHub Pages. Any changes pushed to the `main` branch will automatically update the live site.
